# TÀI LIỆU THAM KHẢO TOÀN DIỆN - TUTOR MATCH PLATFORM

## 1. TỔNG QUAN HỆ THỐNG

### 1.1. Giới thiệu
Tutor Match Platform là một hệ thống kết nối gia sư và học sinh, cho phép:
- Học sinh tìm kiếm và đặt lịch học với gia sư
- Gia sư quản lý hồ sơ và lịch dạy
- Admin quản lý toàn bộ hệ thống
- Hỗ trợ thanh toán và đánh giá

### 1.2. Kiến trúc hệ thống
- **Frontend**: React + TypeScript + Tailwind CSS
- **Backend**: Spring Boot + Java
- **Database**: PostgreSQL
- **Authentication**: JWT
- **File Storage**: Cloudinary
- **Payment**: Tích hợp Payment Gateway

### 1.3. Các vai trò người dùng
- **GUEST**: Khách (chưa đăng nhập)
- **STUDENT**: Học sinh
- **TUTOR**: Gia sư
- **ADMIN**: Quản trị viên

### 2.2. Database Schema

#### Core Tables
- **users**: Thông tin người dùng
- **tutor_profiles**: Hồ sơ gia sư
- **profile_applications**: Hồ sơ đăng ký gia sư
- **bookings**: Đặt lịch học
- **payments**: Thanh toán
- **ratings**: Đánh giá
- **subjects**: Môn học
- **teaching_audiences**: Đối tượng học
- **coupons**: Mã giảm giá
- **messages**: Tin nhắn
- **reports**: Báo cáo

#### Application Tables
- **application_schedules**: Lịch dạy trong hồ sơ
- **application_subject_fees**: Học phí môn học
- **application_teaching_audiences**: Đối tượng nhận dạy
- **application_educations**: Học vấn
- **application_certificates**: Chứng chỉ

### 2.3. API Endpoints

#### Authentication APIs
- `POST /api/auth/login` - Đăng nhập
- `POST /api/auth/register` - Đăng ký
- `POST /api/auth/logout` - Đăng xuất
- `PUT /api/auth/change-password` - Đổi mật khẩu

#### Public APIs
- `GET /api/public/tutors/search` - Tìm kiếm gia sư
- `GET /api/public/tutors/{id}` - Chi tiết gia sư
- `GET /api/public/subjects` - Danh sách môn học

#### Student APIs
- `GET /api/student/bookings` - Danh sách buổi học
- `POST /api/student/bookings` - Đặt lịch học
- `POST /api/student/ratings` - Đánh giá gia sư
- `PUT /api/student/profile` - Cập nhật thông tin

#### Tutor APIs
- `GET /api/tutor/profile` - Thông tin hồ sơ
- `PUT /api/tutor/profile` - Cập nhật hồ sơ
- `GET /api/tutor/schedules` - Lịch dạy
- `GET /api/tutor/bookings` - Quản lý booking

#### Admin APIs
- `GET /api/admin/users` - Quản lý người dùng
- `PUT /api/admin/users/{id}/toggle-enable` - Khóa/mở tài khoản
- `GET /api/admin/applications` - Quản lý hồ sơ
- `PUT /api/admin/applications/{id}/approve` - Duyệt hồ sơ
- `GET /api/admin/coupons` - Quản lý coupon
